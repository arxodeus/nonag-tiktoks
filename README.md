# nonag-tiktoks

A userscript for watching TikTok logged out without the login and open-the-app nags.

To use it, install a userscript manager such as FireMonkey and open [nonag-tiktoks.user.js](https://raw.githubusercontent.com/arxodeus/nonag-tiktoks/main/nonag-tiktoks.user.js).

The script is written without ampersands, angle brackets, carets, asterisks, backslashes or backticks.

EUPL v1.2 or later.
